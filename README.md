# متجر زاد نيكس | ZADNEX STORE
منصة تجارة إلكترونية متطورة لبيع وتوزيع المواد الغذائية، المشروبات، المنظفات، ومستلزمات البيت في المملكة العربية السعودية (مكة المكرمة).

---

## 🌟 الميزات والمواصفات
- **النشاط:** تجارة التجزئة للمواد الغذائية والتموينية والمنظفات والكماليات (كود الأيزك: 471131).
- **السجل التجاري:** 7055435114 | **شهادة سلامة الغذاء:** 101565890.
- **التغطية الحالية:** توصيل فوري داخل مكة المكرمة (وضع الإطلاق التجريبي).
- **نظام الطلب:** تأكيد الطلبات والدفع عند الاستلام مع تحويل الفاتورة تلقائياً إلى واتساب الإدارة (+966 58 076 0890).
- **بوابات الدفع:** مجهزة بلوحة تحكم لتشغيل وإيقاف بوابات الدفع الإلكتروني (Paymob, Tamara, Tabby) بنقرة واحدة.
- **الواجهة:** مبنية بـ Tailwind CSS و Alpine.js متوافقة بالكامل مع كافة الشاشات والأجهزة.
